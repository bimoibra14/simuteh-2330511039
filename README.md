Repositori ini berisi dokumentasi pengerjaan praktikum Computer Vision P1–P4 dan P5–P6 dengan studi kasus identifikasi bercak penyakit cacar daun teh (*Exobasidium vexans*).

## Struktur Proyek

- `notebook/` – Notebook pengerjaan P1–P6.
- `src/` – Kumpulan kode program Python.
- `data/` – Dataset dan label citra.
- `hasil/` – Hasil pengujian dan konfigurasi parameter.
- `requirements.txt` – Daftar pustaka yang digunakan.

## Tahapan Pengerjaan

- **P1–P4:** Pembentukan dataset, analisis kanal warna, perbaikan citra, dan filtering.
- **P5:** Penerapan dan evaluasi metode deteksi tepi Sobel, Prewitt, LoG, dan Canny.
- **P6:** Operasi morfologi, pelabelan komponen, pengukuran bercak, dan evaluasi klasifikasi.

5. Jalankan notebook dari awal hingga akhir.
